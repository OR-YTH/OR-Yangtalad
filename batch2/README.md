# เว็บไซต์กลุ่มงานห้องผ่าตัด โรงพยาบาลยางตลาด

เว็บไซต์: https://or-yth.github.io/OR-Yangtalad/

## แก้ไขเนื้อหา (ไม่ต้องแก้โค้ด)

เนื้อหาทั้งหมดอยู่ใน Google Sheet **"เนื้อหาเว็บห้องผ่าตัด รพ.ยางตลาด"**
https://docs.google.com/spreadsheets/d/1BOz9uPOJTnbdfs0JJFXx5noSZBoh3pV5bBQ75nmyhow/edit

- เพิ่มเนื้อหา: พิมพ์ในแถวว่างถัดไปของแท็บ แล้วติ๊ก "แสดง"
- ซ่อนเนื้อหา: เอาติ๊ก "แสดง" ออก
- แก้แล้วรีเฟรชหน้าเว็บ (อาจช้า 1-2 นาที)
- อ่านรายละเอียดในแท็บ "วิธีใช้" ของชีต

ชีตต้องตั้งแชร์เป็น "ทุกคนที่มีลิงก์ = ผู้มีสิทธิ์อ่าน" เว็บจึงดึงเนื้อหาได้ ถ้าโหลดชีตไม่ได้ เว็บจะแสดงเนื้อหาสำรองที่ฝังไว้ใน `index.html`

## อัลบั้มรูปกิจกรรม

ใช้เมนู **📷 รูปกิจกรรม** ในชีตเนื้อหา (สคริปต์ `รูปกิจกรรม.gs` ใน Apps Script ของชีต)
สร้างอัลบั้ม → อัปโหลดรูปลงโฟลเดอร์ Drive ที่ระบบสร้างให้ → อัปเดตรูปขึ้นเว็บ → ติ๊ก "แสดง"
แต่ละอัลบั้มมีลิงก์ของตัวเอง (`#album-...`) แชร์ต่อใน LINE ได้ ห้ามมีหน้าผู้ป่วยหรือข้อมูลผู้ป่วยในรูป

## สื่อความรู้ในคำแนะนำรายโรค

แท็บ รายโรค คอลัมน์ "สื่อความรู้" วางลิงก์บรรทัดละ 1 รายการ ใส่ชื่อไว้หน้าลิงก์ได้ เช่น `วิดีโอการหายใจหลังผ่าตัด https://youtu.be/...`
- YouTube และไฟล์ Google Drive (วิดีโอ/PDF/รูป) เปิดดูในหน้าเว็บได้เลย ลิงก์รูป .jpg/.png ก็เปิดในเว็บ ลิงก์ PDF และเว็บอื่นเปิดเป็นแท็บใหม่
- ไฟล์ใน Drive ต้องแชร์ "ทุกคนที่มีลิงก์" ง่ายสุดคืออัปโหลดลงโฟลเดอร์ "สื่อความรู้ผู้ป่วย (เว็บไซต์)" ที่แชร์ไว้แล้ว
- ชื่อที่มีคำว่า "วิดีโอ" หรือ "คลิป" ทำให้ไฟล์ Drive เปิดเป็นจอวิดีโอ

## แบบประเมินความพึงพอใจและข้อร้องเรียน

ฟอร์มบนเว็บส่งข้อมูลไปที่ชีตส่วนตัว "ข้อมูลแบบประเมินและข้อร้องเรียน ห้องผ่าตัด (ส่วนตัว)" ผ่านสคริปต์ `แบบประเมิน.gs` (Deploy เป็นเว็บแอป)
วางลิงก์เว็บแอปในชีตเนื้อหา แท็บ ตั้งค่า แถว "ลิงก์ระบบรับแบบประเมิน" แก้คำถามได้ที่แท็บ แบบประเมิน
คะแนนเฉลี่ยแสดงบนเว็บอัตโนมัติเมื่อมีผู้ประเมินครบ 10 คน (12 เดือนล่าสุด) ข้อมูลรายบุคคลไม่เปิดเผย

## แชร์อัลบั้มไป Facebook / LINE

ในหน้าอัลบั้มมีปุ่ม "แชร์ Facebook" "ส่งใน LINE" และ "คัดลอกลิงก์"
ให้ Facebook ขึ้นชื่อกิจกรรมกับรูปปกของอัลบั้มนั้น ต้องมีหน้าแชร์ `share/<รหัสอัลบั้ม>.html`
ซึ่ง GitHub Actions สร้างให้เองทุก 30 นาที (`.github/workflows/share-pages.yml` + `tools/make-share-pages.mjs`)
ถ้ายังไม่มีหน้าแชร์ ปุ่มจะใช้ลิงก์อัลบั้มปกติ (Facebook ขึ้นโลโก้และชื่อเว็บแทน)
อยากให้สร้างทันที: แท็บ Actions → หน้าแชร์อัลบั้ม → Run workflow

## สถิติการผ่าตัด

ดึงตัวเลขสรุปจากระบบทะเบียนห้องผ่าตัด (`getPublicStats` ใน Apps Script) อัตโนมัติ ไม่มีชื่อหรือ HN ผู้ป่วย
- **รายเดือน:** เดือนปัจจุบัน
- **รายปี:** ปุ่ม "รายปี" รวมตัวเลขทีละเดือนผ่าน `?action=publicStats&month=YYYY-MM` แสดงกราฟรายเดือน ตาราง และแยกตามแผนก เลือกได้ 3 ปีล่าสุด
  - ค่าเริ่มต้นเป็นปีงบประมาณ (ต.ค.–ก.ย.) ถ้าอยากใช้ปีปฏิทิน แก้ `STATS_YEAR_START = 10` เป็น `1` ใน `index.html`
  - ถ้าหน้าเว็บขึ้น "ยังแสดงสถิติรายปีไม่ได้" แปลว่า `doGet` ของระบบทะเบียนไม่ได้ส่งค่าเดือนต่อ ต้องเป็น `getPublicStats(e.parameter.month)`

- **10 อันดับการผ่าตัด:** ปุ่มบนการ์ดในส่วน "ศัลยกรรมที่ให้บริการ" ดึงจาก `?action=topOps` (ไฟล์ `ทะเบียน_10อันดับ.gs` ในระบบทะเบียน) ช่วง 12 เดือนล่าสุด หัตถการที่มีน้อยกว่า 3 รายไม่แสดง ถ้ายังไม่ได้ติดตั้ง ปุ่มจะไม่ขึ้น

ถ้า Deploy ระบบทะเบียนใหม่แล้วลิงก์เปลี่ยน ให้แก้ค่า `STATS_URL` ใน `index.html` บรรทัดเดียว

## 5ส. ห้องผ่าตัด ชั้น 5 (เมนู "5ส.")

- **แผนผัง 2 มิติ + ผู้รับผิดชอบ:** แผนผังสร้างจากข้อมูลผังเดียวกับ `5s-3d.html` (ฝังอยู่ใน `index.html`) แตะห้องหรือเลือกโซนเพื่อดูคำบรรยายโซนและรายชื่อ บนมือถือจะซูมเข้าโซนที่เลือก
  - ชื่อโซนและคำบรรยาย: แท็บ **5ส-โซน** (บรรทัดที่ขึ้นต้น `จุดเน้น 5ส.:` แสดงเป็นกล่องเน้น)
  - รายชื่อ: แท็บ **5ส-ผู้รับผิดชอบ** (โซน | รหัสห้อง | ชื่อห้อง / พื้นที่ | ผู้รับผิดชอบหลัก | ผู้รับผิดชอบร่วม | แสดง) แถวที่ไม่มีรหัสห้องใส่ `–` แล้วตั้งชื่อให้มีคำเดียวกับในแผนผัง
  - ถ้ากั้นห้องใหม่/รูปผังเปลี่ยน ต้องแก้ข้อมูลผังใน `5s-3d.html` แล้วสร้าง `index.html` ใหม่
- **ภาพกิจกรรม:** แท็บ **5ส-กิจกรรม** (คอลัมน์เหมือนแท็บ ข่าวสาร) เปิดเป็นอัลบั้มเหมือนข่าวสาร เรียงตามลำดับแถว ใช้โฟลเดอร์ Google Drive ได้ (รูปกิจกรรม.gs รุ่นใหม่รองรับแท็บนี้)
- **ก่อน–หลัง:** แท็บ **5ส-ก่อนหลัง** (หัวข้อ | วันที่ | รูปก่อน | คำบรรยายก่อน | รูปหลัง | คำบรรยายหลัง | แสดง)
- รูปชุดแรก (จากรายงานกิจกรรมและภาพเปรียบเทียบก่อน–หลัง) อยู่ในโฟลเดอร์ `5s-act/` (72 รูป) และ `5s-ba/` (36 รูป) ของ repo นี้ ในชีตใส่เป็นชื่อไฟล์ เช่น `5s-act/a01-1.jpg`
- `5s-3d.html` แผนผัง 3 มิติ ใส่รายชื่อผู้รับผิดชอบไว้ใน `CARETAKERS` แล้ว (ปุ่ม "ผู้รับผิดชอบ" บนโมเดล) ถ้ารายชื่อเปลี่ยนต้องแก้ทั้งชีตและไฟล์นี้

## ระบบสำหรับเจ้าหน้าที่

ปุ่ม 🔒 บนเมนูและลิงก์ "สำหรับเจ้าหน้าที่" ท้ายเว็บ เปิดรายการระบบจากแท็บ **ระบบเจ้าหน้าที่** ในชีต (ไอคอน | ชื่อระบบ | คำอธิบาย | ลิงก์ | แสดง)
เจ้าหน้าที่บันทึกลิงก์ `https://or-yth.github.io/OR-Yangtalad/#staff` ไว้เปิดตรงได้ ทุกระบบต้องมีล็อกอินของตัวเอง เพราะลิงก์นี้ใครก็เปิดดูรายชื่อระบบได้
